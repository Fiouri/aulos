# Aulos

An open-source, offline-first Android music player. It plays the music already on your phone, works with zero network, and will later stream and download from pluggable sources (Internet Archive, Jamendo) and pair with [Nuclear](https://github.com/nukeop/nuclear) on the desktop. No backend, no account, no tracking.

"Aulos" is a codename; the app will be renamed before its first public release.

## Status

Milestone **M1 (Offline player)**: browse the device library by songs, albums and artists; play with a queue, shuffle, repeat and gapless transitions; background playback with lock-screen, notification and Bluetooth controls; sleep timer; playlists (with JSON import/export), favorites and listening history; instant offline search that ignores accents in every script, Greek included. Streaming sources arrive in M2. See [SPEC.md](SPEC.md) for the full plan and milestones.

## Build from source

Requirements: Node.js 22, npm, JDK 17 (Temurin), Android SDK. Builds are local; Expo Go and EAS are not used.

```bash
npm ci
npm run typecheck
npm run lint
npm test -- --ci

npm run android:prebuild          # generates android/ (not committed)
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

On Windows use `.\gradlew.bat assembleRelease`. Release builds are minified with R8 and resource shrinking. Until M4 the release build is signed with the debug keystore generated by prebuild; it is for testing only.

For development on a device: `npx expo run:android`.

## Testing on a device

```powershell
.\scripts\test-media.ps1 -Mode standard   # test albums (Greek, gapless FLAC, two discs) via adb
maestro test -e EXPECTED_TRACKS=<music count> .maestro/
.\scripts\test-media.ps1 -Mode bulk       # adds 2,000 short tracks for performance runs
.\scripts\soak-playback.ps1               # 1 h screen-off playback check
.\scripts\test-media.ps1 -Mode clean      # removes the test music again
```

`test-media.ps1` needs ffmpeg and adb on PATH.
