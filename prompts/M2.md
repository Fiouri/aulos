## Scope
1. Networking foundation (src/net)
   - `httpJson` wrapper over fetch:
     - per-request timeout and AbortController cancellation;
     - retry with exponential backoff and jitter on network errors, 429 (honour Retry-After) and 5xx, max 3 attempts;
     - User-Agent `Aulos/<version> (+https://github.com/<repo>)`, using a constant from app config;
     - response validation with zod (MIT); an invalid shape becomes a typed error, never a crash.
   - Network state via expo-network (MIT).
   - Migration 005:
     - `http_cache` table (SPEC §6) plus a TTL cache layer (search 1 h, metadata 24 h), to be polite to archive.org and to make repeat views instant;
     - add `license_url` and `attribution` columns to tracks.
   - Android: unblock INTERNET; add a network security config with cleartextTrafficPermitted=false. Justify INTERNET in SESSIONS.md.
2. Provider layer (src/providers)
   - Implement the SourceProvider interface from SPEC §4, a ProviderRegistry and capability flags, designed so another provider can be added later without touching the UI.
   - LocalProvider wraps the existing library search, so the Search tab uses one code path.
   - Errors are typed: NetworkError, RateLimitError, NotFoundError, InvalidResponseError. The UI maps each to a clear English message via t().
3. Internet Archive provider
   - Search mediatype:audio items that contain playable audio files. Return items as albums and their audio files as tracks.
   - Item → tracks via the metadata API:
     - title, creator/artist, album, track number and length from file or item metadata, with sensible fallbacks;
     - skip non-audio and derivative-only noise (spectrograms, thumbnails, playlists, torrents).
   - Formats: stream the MP3 derivative (VBR MP3 or MP3). Download format per Settings: MP3 (default), or FLAC/Ogg when the item has them.
   - provider_ref = `identifier/filename`. Store licenseurl as license_url and creator as attribution.
   - Security:
     - IA filenames come from the network: encode them in URLs, and never use them as local path segments;
     - local download names are derived from a hash of provider_ref plus a whitelisted extension.
   - Integrity: verify the downloaded file's md5 against the metadata API's md5 when present. On mismatch, delete the file and mark the download failed.
4. Playback of remote tracks
   - PlayerService resolves stream URLs at play time through the provider (resolveStream). The queue can mix local, downloaded and streaming tracks.
   - A downloaded track always plays from its local file.
   - Offline: a streaming-only track is skipped with a "Not available offline" toast, and the queue continues.
   - Track info sheet: provider, licence (tappable link) and attribution.
5. Downloads (src/downloads)
   - DownloadManager is a persisted state machine in the downloads table: queued → downloading → paused → completed | failed.
     - Concurrency 2.
     - Resumable via the expo-file-system SDK 58 API.
     - Paused downloads resume after app restart or when the network returns.
   - Settings:
     - Wi-Fi only (default on);
     - storage limit (default 2 GB);
     - download format.
     Enforce the limit before starting a download.
   - Actions:
     - download a track, a whole album, or a whole playlist (remote tracks only);
     - cancel, retry, delete one, delete all.
     On completion, set tracks.local_path.
   - Downloads screen: active with progress, completed, failed with retry, storage used / limit.
   - Background behaviour (whether downloads pause when the app is backgrounded) is measured and recorded in SESSIONS.md. A download foreground service is out of scope.
6. Search tab
   - Source switcher: Library (default) and Internet Archive. Remote search is debounced 400 ms.
   - Remote results: play, play next, add to queue, add to playlist, favourite, download, open album. Remote album detail reuses the album screen.
   - Settings → Sources: Internet Archive on/off (default on) and the download settings.
7. Fixtures and tests
   - scripts/record-fixtures.ps1 records real Internet Archive responses once into test/fixtures/archive/; the recorded files are committed. Jest never touches the network: the provider is tested against the fixtures.
   - Unit tests cover:
     - httpJson (timeout, retry/backoff, Retry-After, zod failure);
     - cache TTL;
     - IA mapping, including missing fields and non-audio files;
     - IA filename sanitising and md5 verification;
     - DownloadManager transitions, resume after restart, limit enforcement, Wi-Fi-only gating and cleanup;
     - offline skip in the queue;
     - migration 005, including a re-run no-op.
   - Maestro (keep all 8 M0/M1 flows green):

     - m2-download-offline: download an IA track, then `adb shell cmd connectivity airplane-mode enable`, play it from Downloads, verify it plays, then disable airplane mode.
     Network flows run on the S23. The API 31 emulator runs the offline flows plus m2-download-offline.
