## Scope
1. Search normalisation
   - Migration 002 adds normalised columns to tracks (title_norm, artist_norm, album_norm, album_artist_norm).
   - It rebuilds tracks_fts and its triggers over the normalised columns and backfills existing rows.
   - Normalisation is one pure TS function used both when writing tracks and when querying: NFD, strip all \p{M}, lowercase, ς → σ, collapse whitespace.
   - Unit tests: "χατζιδακις" finds "Χατζιδάκις", "ΑΓΑΠΗ" finds "αγάπη", "Beyonce" finds "Beyoncé", "Mötley" finds "Motley".
   - Search queries use FTS5 prefix matching per token.
2. Library browse
   - Library tab with Songs, Albums, Artists views (segmented), backed by the existing views/queries.
   - Album detail (tracks in disc/track order) and artist detail (albums, then all tracks).
   - Sorting: Songs by title/artist/date added; Albums by name/artist/year if available.
   - Lists use @shopify/flash-list and stay smooth at 2,000+ tracks.
   - Artwork: extend modules/media-store with loadArtwork(contentUri: string, sizePx: number). It uses ContentResolver.loadThumbnail on API 29+ and the album-art content URI below, caches to the app cache dir keyed by albumId + size, and returns a file:// URI or null. It runs off the main thread. Unit-test the TS cache logic; manually verify the Kotlin on device.
   - Rescan on app resume only when the MediaStore version or generation changed (MediaStore.getVersion / getGeneration on API 30+; on older APIs, compare count + max dateModified).
   - Settings → Library folders: list distinct folders (RELATIVE_PATH on API 29+, parent dir of the data path below), with toggles. Excluded folders are filtered at scan time and stored in kv.
3. Player (src/player + player store)
   - Wrap expo-audio AudioPlaylist in one PlayerService, the only module that touches expo-audio.
   - Queue operations: play now, play next, add to queue, remove, move, clear, shuffle (keep original order to unshuffle), repeat off/all/one, seek, previous (restart if position > 3 s, else previous track).
   - Persistence: queue track ids, index and position are saved in kv (throttled to at most once per 5 s while playing, and on pause/background). They are restored on start without auto-playing.
   - Background and lock screen:
     - setAudioModeAsync with shouldPlayInBackground true and interruptionMode doNotMix.
     - setActiveForLockScreen with title, artist, album and artwork, updated on every track change.
     - Pause on headphone/Bluetooth disconnect (verify expo-audio's built-in behaviour; do not duplicate it).
     - Bluetooth and headset buttons work through the media session.
   - Gapless: consecutive tracks in the queue play through AudioPlaylist without a gap. Record in SESSIONS.md whether expo-audio delivers true gapless on Android with the test album (scope 8). If it does not, say so and do not fake it with crossfades.
   - Missing files: a track whose file was deleted after the last scan is skipped with a toast, and its row is removed on the next scan.
   - Sleep timer: 15, 30, 45 or 60 minutes, or end of current track.
     - Store a deadline timestamp, enforce it on every playback status update and with a timer, then fade out over 5 s and pause.
     - Verify it fires with the screen off.
