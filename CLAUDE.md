# Aulos — agent guide

**SPEC.md is the source of truth.** Read it before any change. If a task conflicts with it, stop and ask. Milestone prompts live in `prompts/`; the session log and on-device checklists live in `SESSIONS.md`.

## Stack

- Expo SDK 58 (React Native 0.88), TypeScript strict (`noUncheckedIndexedAccess`), expo-router (`app/`, native tabs).
- Android only. Continuous Native Generation: `android/` is generated by prebuild and gitignored. Never edit it by hand; change `app.config.ts` or a config plugin.
- SQLite via expo-sqlite behind the `Db` interface (`src/db/types.ts`); tests use better-sqlite3 through `test/node-db.ts`.
- Local Kotlin Expo module `modules/media-store` (MediaStore audio query).
- State: Zustand (`src/stores`). i18n: i18next + react-i18next, English only (`src/i18n/en.ts`).
- Tests: Jest (jest-expo) + React Native Testing Library; Maestro flows in `.maestro/`.
- Check current docs (Context7) before using any Expo/library API; do not code APIs from memory.

## Commands

```bash
npm run typecheck          # tsc --noEmit
npm run lint               # eslint . --max-warnings 0
npm test -- --ci           # jest
npm run format             # prettier --write .
npm run android:prebuild   # expo prebuild -p android --clean
cd android && ./gradlew lint assembleRelease
```

Behind the TLS-intercepting proxy on the dev machine, prefix Expo CLI commands with `NODE_TLS_REJECT_UNAUTHORIZED=0` and run Gradle with `GRADLE_OPTS=-Djavax.net.ssl.trustStoreType=Windows-ROOT`. Never set these globally or commit them.

## Conventions

- Every UI string goes through `t()`; add keys to `src/i18n/en.ts` (keys are type-checked).
- Schema changes are new forward-only migrations in `src/db/migrations/` (append, never edit an applied one) with tests.
- Pure logic (diffs, mapping) lives in plain modules with unit tests; native and UI layers stay thin.
- Functional components, async/await, early returns, no `any`, no placeholder code or TODO stubs.
- New dependencies must be GPL-3.0-compatible; record licence checks in `SESSIONS.md`.
- No network calls, analytics or telemetry unless SPEC.md asks for them.

## Privacy

- No real IP addresses, device serials, hostnames, or names/artwork from the owner's music library in commits, docs, tests or screenshots. Use neutral values: LAN `192.168.1.50`, Tailscale `100.64.0.10`, `<device-serial>`, `<phone-hostname>`, fictional track/artist names.
- Screenshots come only from an emulator with `scripts/test-media.ps1 -Mode screenshots` media and `node scripts/mock-jam.ts --port 4120 --fixture screenshots` (PC at 10.0.2.2:4120), via `scripts/store-screenshots.yaml`. Open every PNG before committing it.
- `scripts/check-privacy.ps1` (also in CI) fails on Tailscale addresses outside `src/**/__tests__` and on any value in the local, gitignored `.privacy-denylist`. Real values go only in that file.

## Verification gate

Run before reporting any work done, and in CI:

```bash
npm run typecheck && npm run lint && npm test -- --ci
.\scripts\check-privacy.ps1
npm run android:prebuild && cd android && ./gradlew lint assembleRelease
maestro test .maestro/   # or the on-device checklist in SESSIONS.md
```

## Never commit

Keystores (`*.jks`, `*.keystore`), `keystore.properties`, passwords, API keys, `.env` files or any other secret. Release signing keys live outside the repo.
